A full-stack issue management application with an AI-powered summarization feature.

- 📊 Dashboard with issue metrics and status distribution.
- 📋 CRUD operations, filtering, search, and Kanban workflow.
- 🧠 AI-generated summaries and recommended next steps using OpenRouter.
- 🛡️ Backend validation with Zod and Mongoose.
- 🌐 Deployed using Vercel, Render, and MongoDB.
