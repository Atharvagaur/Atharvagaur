### CareTrack: Full-Stack Operations Issue Tracker
> *Status: in development*

A full-stack issue-tracking platform for operations teams, with a Kanban workflow, live dashboard metrics and LLM-generated summaries.

- REST APIs for issue creation, updates, filtering and management

---

### RAG-Based Intelligent Learning Assistant
A modular Retrieval-Augmented Generation app that answers questions **strictly from the document you upload**.

- Pipeline built with **LangChain + ChromaDB + Groq-hosted LLMs**
- Semantic chunking, vector retrieval and history-aware conversations
- Lightweight embeddings to keep retrieval and memory usage low
- Full-stack deployment with **FastAPI** (Render) and **React** (Vercel), auto-redeployed on every GitHub push (CI/CD)

`Python` `LangChain` `ChromaDB` `FastAPI` `React` `Groq`

---

### Cross-Dataset Generalization in ML-Based DDoS Detection
*Research paper*

Do DDoS detectors trained on one dataset still work on another? This study measures how performance degrades under distribution shift.

- Reproducible pipeline using **Random Forest, XGBoost, LightGBM and Isolation Forest** across **3 CIC datasets**
- Cut **77 network-flow features down to 20** using mutual-information selection
- Frozen-model cross-dataset evaluation that exposes the generalization gap
- **SHAP**, feature ablation and five-seed analysis to diagnose model sensitivity and make results reproducible

`Python` `scikit-learn` `XGBoost` `LightGBM` `SHAP`
